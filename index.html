木火土金水五族。发光粒子 = 行料：核心 1px = 族群色（谁产的），辉光 = 阴阳（黄辉=阳料/营养，白辉=阴料/废物）。
生：i 排阳料 → i+1 吃（E+）；克：i 排阴料 → i+2 耗能回收（E−）。吃一份才排一份，物质守恒。
细胞随机游走，碰到才算，不主动追。能量 E=0 → 死；E 达分裂能量 → 分裂成两个半能量细胞。看它们能否共存，还是一方独大后崩解。

活性 · 气（每族独立）
活性 = 气：乘在"作用于个体的一切力"上 —— 决定觅食、追捕、逃逸的效率。
把某一族调低 → 它行动迟缓 → 生克效率下降 → 衰；调高 → 活跃 → 旺。
这就是"太过 / 不及"的直接旋钮。
噪声（随机性）
噪声 = 各向同性随机扰动（细胞的布朗运动成分）。
调低 → 运动更有方向性（趋化/追捕占主导）；调高 → 更接近随机游走。

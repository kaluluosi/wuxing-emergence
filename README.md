**五行是不是一套合法的动力学语法？——一个数值实验。**

## 这是什么

起点是一个"跑起来不像椋鸟群"的 boids demo；终点是一台能演示 **"耗散结构从稳态滑向死态"** 的五行生态引擎。

- **行料分阴阳**（v2）：**阳料**（黄辉·营养）`i → i+1` 吃掉 → 能量 `E +`；**阴料**（白辉·废物）`i → i+2` 碰到 → 能量 `E −`
- **生与克是同一种料流的正负两端** —— **克不是"杀死"，是"排污/代偿"**
- **单能量账户**：能量是唯一货币 —— `E = 0` → 死；`E = 100` → 分裂成两个 `E = 50`
- **物质严格守恒**：吃一份才排一份（1 进 1 出），总量恒定
- **开放系统**：**投喂口**从外部注入能量；**断供 → 必然全死**（耗散结构的热力学宿命）
- **关键**：出生/死亡**不用计时器、不用固定概率** —— 它们是**资源账户的输出**
  （否则"休囚死"永远涌现不出来，答案会被写进参数里）

## 核心发现

| 中医表述 | 动力学对应 | 实测结论 |
|---|---|---|
| 生克休囚死 | 耗散结构：流断则结构塌 | 稳态是"高流量"假象（火每 10s 换 2.4 遍）|
| 相乘相侮 | 克链负反馈被破坏 | 压火 → 金 ×7（相侮）、木 −83%（相乘）|
| 物极必反 | 延迟负反馈 → 滞后振荡 | 火 13 → 65（"重阴必阳"）|
| 太过 / 不及 | **对称性破缺** | 对称参数造不出偏枯，只能全体兴亡 |
| 旺衰 | **活性（气）** | 活性 0.4→1.0，觅食效率翻 3.5 倍 |
| 旺衰的度量 | **人均内禀率** | 总量率是"伪旺"（总量 = 人均 × 数量）|
| 头痛医头之误 | 单行干预打破比例 | 单行补料死得比不干预更早 |
| 附子回阳救逆 | 打通**传输通道**（非提高消耗）| 附子起死回生（→826），激素透支速死（→0）|
| 同病异治 | 确定性**混沌** | 7 次实验 7 个死序，甚至一次谁都没死 |

> **一句话**：规律清晰，个体不可复制。

## 快速开始

### 在线
打开 <https://kaluluosi.github.io/wuxing-emergence/>

### 本地

```bash
git clone https://github.com/kaluluosi/wuxing-emergence
cd wuxing-emergence
# 双击 index.html 即可
# 或起个静态服务器：
python -m http.server 8000   # → http://localhost:8000
```

**玩什么**：
- 面板「**活性 · 气**」→ 把某一行调低（不及）或调高（太过），看系统怎么崩
- 面板「**显示 → 速率按个体**」→ 切换总量 / 人均口径，看"伪旺"如何消失
- 观察右上角监视器：数量 / 繁殖率 / 死亡率 / 产料率 / 耗料率 / 料存量

## 诚实声明

**这不是"破译"，是"重新诠释"。**
传统中医的阴阳**有时确实指"态"**（寒热虚实）。把阴阳读成"率"，是给旧词赋新义 ——
**我们在造一门新学说，不是在挖古墓。**

本模型是**玩具级的**：它证明的是"**阴阳五行是一套合法的动力学语法**"（能算、能证伪、能预测），
**不是**"古人的宇宙观被证实"。参数是唯象的，不来自生理测量。

完整局限与待验证假设见 [`docs/paper.md`](docs/paper.md) §5、§6。
